Learning Buddy
Übungs-App für die Realschule

Üben, bis es sitzt.

Lass dir von einer KI Übungsfragen zu jedem Thema erstellen, importiere sie und übe sie als Test. Learning Buddy zeigt dir, was du schon kannst und was noch hakt.

Für Windows herunterladen
Kostenlos · Windows 10/11 · alle Versionen

Was Learning Buddy kann

Fragen

KI-Fragen importieren

Der Prompt-Builder erstellt den passenden Auftrag für ChatGPT, Claude & Co. Die Antwort fügst du einfach ein.

Üben

Tests wie in der Schule

Multiple Choice, Freitext und Formeln. Mit Punkten, Note und Rückblick auf jede Frage.

Analyse

Wissenslücken finden

Themen nach Schwäche sortiert, ein Fehlerheft für falsche Antworten und jeden Tag fünf Wiederholungsfragen.

Schule

Schul-Cockpit

Noten, Klassenarbeiten und Ferien im Blick, auf Wunsch per iCal-Kalender. Tests und Notenübersicht als PDF.

So installierst du es

  1. Installer herunterladenÜber den Knopf oben (ca. 125 MB).
  2. Doppelklick auf LearningBuddy-Setup.exeDer Assistent legt eine Verknüpfung im Startmenü an, auf Wunsch auch auf dem Desktop.
  3. Profil anlegen und loslegenDeine Daten bleiben auf deinem PC. Kein Konto, keine Cloud.

Windows warnt beim ersten Start? Der Installer ist nicht signiert, deshalb zeigt Windows „Der Computer wurde durch Windows geschützt“. Klicke auf Weitere Informationen und dann auf Trotzdem ausführen.
